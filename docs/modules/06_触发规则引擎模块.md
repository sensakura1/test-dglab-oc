# 触发规则引擎模块开发文档

## 1. 模块职责

触发规则引擎负责接收 `FocusEvent`，执行冷却、次数、锁定、强度范围、持续时间范围等校验，最终生成设备动作。

## 2. 关键接口

```ts
interface TriggerEngine {
  handle(event: FocusEvent): Promise<TriggerResult>;
  canTrigger(event: FocusEvent): TriggerDecision;
}

interface TriggerResult {
  triggered: boolean;
  reason?: string;
  activation?: CoyoteActivation;
}
```

## 3. 规则顺序

```text
检查专注是否开启
  -> 检查急停锁定
  -> 检查设备模式和连接状态
  -> 检查全局冷却
  -> 检查事件级冷却
  -> 检查周期最大触发次数
  -> 计算强度和持续时间
  -> 调用设备适配器
```

## 4. 强度和时间计算

- 固定值按固定值执行。
- 范围值从区间中随机选取。
- 最终值必须经过 `maxIntensity` 和 `maxDurationMs` 限幅。

## 5. 连续分心升级

可选功能：同一会话内连续触发 `DISTRACTION_DETECTED` 时，提高强度，但不得超过最大强度。

## 6. 测试点

- 冷却期内不触发。
- 达到次数上限后不触发。
- 强度和时间不会超过上限。
- 测试触发走完整规则流程。
