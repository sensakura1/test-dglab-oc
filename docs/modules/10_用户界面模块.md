# 用户界面模块开发文档

## 1. 模块职责

用户界面模块负责展示专注状态、配置入口、设备状态、触发日志和急停控制。

## 2. 主界面区域

- 专注控制区：开始、暂停、恢复、结束。
- 状态展示区：写作中、离开中、分心中、空闲中、冷却中、锁定中。
- 计时展示区：本次专注剩余时间、离开时间、分心时间、空闲时间。
- 规则配置区：写作范围、分心范围、忽略范围、暂停范围。
- 触发配置区：强度范围、持续时间范围、冷却、次数上限。
- 设备区：模拟/真实模式、连接、断开、测试触发。
- 安全区：急停按钮、锁定状态、解锁按钮。
- 日志区：最近触发和错误记录。

## 3. 交互要求

- 急停按钮始终可见。
- 真实设备模式开启时需要二次确认。
- 配置修改后应即时校验。
- 规则新增后无需重启生效。
- 隐私开关必须清晰展示。

## 4. 状态提示

| 状态 | UI 提示 |
| --- | --- |
| 写作中 | 显示当前命中的写作规则 |
| 离开中 | 显示离开计时和触发剩余时间 |
| 分心中 | 显示分心规则和触发剩余时间 |
| 空闲中 | 显示无输入计时 |
| 冷却中 | 显示冷却剩余时间 |
| 锁定中 | 禁止触发，显示解锁按钮 |

## 5. 测试点

- 开始/暂停/结束状态正确。
- 急停在所有页面可操作。
- 配置非法时显示错误。
- 测试触发能显示模拟结果。
