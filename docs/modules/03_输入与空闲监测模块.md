# 输入与空闲监测模块开发文档

## 1. 模块职责

输入与空闲监测模块负责统计用户键盘和鼠标活跃度，用于判断是否长时间没有写作输入。

## 2. 设计边界

- 不记录具体键入内容。
- 不保存剪贴板内容。
- 不分析文本语义。
- 只记录输入发生时间和计数。

## 3. 关键接口

```ts
interface InputActivityMonitor {
  start(): void;
  stop(): void;
  getIdleSeconds(): number;
  markActivity(activity: InputActivity): void;
  onIdle(handler: (idleSeconds: number) => void): void;
}

interface InputActivity {
  type: "keyboard" | "mouse";
  occurredAt: string;
  inWritingScope: boolean;
}
```

## 4. 空闲判断

- 只有专注会话进行中才统计。
- 默认只统计写作范围内的键盘输入为有效写作活跃。
- 鼠标活动可用于判断用户未离开电脑，但不一定清零写作空闲。
- 达到 `idleGraceSeconds` 后生成 `IDLE_TOO_LONG`。

## 5. 异常处理

| 异常 | 处理 |
| --- | --- |
| 权限不足无法监听 | UI 提示并禁用空闲触发 |
| 输入事件过多 | 只更新时间戳，不逐条记录 |
| 专注暂停 | 暂停空闲计时 |

## 6. 测试点

- 键盘输入后空闲计时清零。
- 长时间无输入生成事件。
- 不保存具体输入内容。
- 暂停专注时不生成空闲事件。
