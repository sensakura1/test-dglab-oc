# 范围匹配模块开发文档

## 1. 模块职责

范围匹配模块根据当前窗口信息判断用户处于写作范围、分心范围、忽略范围、暂停范围或未知范围。

## 2. 匹配优先级

优先级从高到低：

1. 暂停范围。
2. 忽略范围。
3. 分心范围。
4. 写作范围。
5. 未知范围。

分心范围优先于写作范围，用于处理同一浏览器中标题同时命中多个关键词的情况。

## 3. 关键接口

```ts
interface ScopeMatcher {
  match(info: ActiveWindowInfo, config: AppConfig): ScopeMatchResult;
}

interface ScopeRule {
  name: string;
  enabled?: boolean;
  process?: string;
  titleKeywords?: string[];
  urlKeywords?: string[];
}

interface ScopeMatchResult {
  scope: "writing" | "distraction" | "ignore" | "pause" | "unknown";
  ruleName?: string;
}
```

## 4. 匹配规则

- 进程名大小写不敏感。
- 关键词匹配默认大小写不敏感。
- 同一组内多个字段为“任一命中即可”。
- 规则禁用时不参与匹配。

## 5. 隐私要求

匹配结果只输出规则名称，不输出完整标题和 URL。

## 6. 测试点

- 白名单命中返回 `writing`。
- 黑名单命中返回 `distraction`。
- 忽略名单命中不触发。
- 暂停范围优先级最高。
