# 郊狼设备适配模块开发文档

## 1. 模块职责

郊狼设备适配模块负责封装设备通信细节，对上层提供统一的连接、激活、停止和状态查询接口。

## 2. 适配器类型

| 适配器 | 说明 |
| --- | --- |
| `MockCoyoteAdapter` | 默认模拟设备，用于开发和测试 |
| `RealCoyoteAdapter` | 按实际郊狼接口实现 WebSocket 或 HTTP 通信 |

## 3. 关键接口

```ts
interface CoyoteAdapter {
  connect(): Promise<void>;
  disconnect(): Promise<void>;
  activate(options: CoyoteActivation): Promise<void>;
  stop(): Promise<void>;
  getStatus(): Promise<CoyoteStatus>;
}
```

## 4. 安全要求

- 默认使用模拟适配器。
- 真实设备模式需要用户二次确认。
- 设备断线时不得执行激活。
- `stop()` 必须尽可能快速执行。
- 配对 token 不得写入普通日志。

## 5. Mock 行为

模拟适配器不连接真实设备，只记录：

- 调用时间。
- 强度。
- 持续时间。
- 通道。
- 模式。

## 6. 测试点

- Mock 模式可完整跑通触发流程。
- 断线状态下拒绝激活。
- stop 调用可在任何状态执行。
- 真实接口异常会返回明确错误。
