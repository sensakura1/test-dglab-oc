# 日志与隐私模块开发文档

## 1. 模块职责

日志与隐私模块负责记录运行事件、触发事件、错误信息和安全事件，同时保证敏感信息脱敏。

## 2. 日志格式

推荐 JSON Lines：

```json
{"time":"2026-07-09T12:00:00+08:00","level":"info","event":"triggered","type":"FOCUS_LEFT","rule":"OC 文档","intensity":25,"duration_ms":1500}
```

## 3. 禁止记录

- 写作正文。
- 具体键入内容。
- 明文配对 token。
- 默认状态下的完整 URL。
- 默认状态下的完整窗口标题。

## 4. 关键接口

```ts
interface LogService {
  info(event: string, data?: Record<string, unknown>): void;
  warn(event: string, data?: Record<string, unknown>): void;
  error(event: string, data?: Record<string, unknown>): void;
  listRecent(limit: number): Promise<LogEntry[]>;
}
```

## 5. 脱敏规则

- token 显示为 `***`。
- URL 默认只记录规则名称。
- 窗口标题默认只记录规则名称。
- 调试模式日志应有明显标记，并允许用户关闭。

## 6. 测试点

- 触发事件有日志。
- 错误事件有日志。
- token 不出现在日志中。
- 默认不记录完整标题和 URL。
