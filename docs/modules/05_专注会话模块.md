# 专注会话模块开发文档

## 1. 模块职责

专注会话模块负责管理开始、暂停、恢复、结束专注周期，并统计离开时间、分心时间、空闲时间和触发次数。

## 2. 状态机

```text
STOPPED -> WRITING
WRITING -> LEFT
WRITING -> DISTRACTED
WRITING -> IDLE
LEFT -> WRITING
DISTRACTED -> WRITING
IDLE -> WRITING
任意状态 -> PAUSED
任意状态 -> LOCKED
任意状态 -> STOPPED
```

## 3. 关键接口

```ts
interface SessionManager {
  start(): void;
  pause(): void;
  resume(): void;
  stop(): void;
  updateScope(match: ScopeMatchResult): FocusEvent[];
  updateIdle(idleSeconds: number): FocusEvent[];
  getSnapshot(): SessionSnapshot;
}
```

## 4. 事件生成

- 离开写作范围超过 `leaveGraceSeconds` 生成 `FOCUS_LEFT`。
- 命中分心范围超过 `distractionGraceSeconds` 生成 `DISTRACTION_DETECTED`。
- 空闲超过 `idleGraceSeconds` 生成 `IDLE_TOO_LONG`。
- 会话结束且未完成目标可生成 `SESSION_TIMEOUT`。

## 5. 防重复规则

同一状态持续期间只生成一次事件，直到用户回到写作范围或会话重置。

## 6. 测试点

- 开始、暂停、恢复、结束状态正确。
- 离开计时达标后只生成一次事件。
- 回到写作范围后计时清零。
- 分心优先级高于普通离开。
