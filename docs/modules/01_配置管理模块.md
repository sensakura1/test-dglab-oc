# 配置管理模块开发文档

## 1. 模块职责

配置管理模块负责加载、校验、补全、保存用户配置，并在配置异常时提供安全默认配置。

## 2. 输入输出

输入：

- 本地配置文件。
- UI 修改后的配置对象。
- 程序默认配置模板。

输出：

- 已校验的 `AppConfig`。
- 配置错误列表。
- 保存结果。

## 3. 配置文件

默认文件名建议为 `config.json`，存放在用户数据目录或程序工作目录。配置文件必须使用 UTF-8 编码。

## 4. 关键接口

```ts
interface ConfigService {
  load(): Promise<AppConfig>;
  save(config: AppConfig): Promise<void>;
  validate(config: unknown): ConfigValidationResult;
  mergeDefaults(config: Partial<AppConfig>): AppConfig;
  resetToSafeDefaults(): Promise<AppConfig>;
}
```

## 5. 校验规则

- `deviceMode` 只能是 `mock` 或 `real`。
- `maxIntensity` 必须在 `0 - 100`。
- `maxDurationMs` 必须大于 `0`。
- 所有时间配置必须大于等于 `0`。
- 强度范围不得超过 `maxIntensity`。
- 持续时间范围不得超过 `maxDurationMs`。
- 真实设备配置缺少 endpoint 时，不允许进入真实设备模式。

## 6. 安全默认值

配置异常时：

- `enabled = false`
- `deviceMode = "mock"`
- `maxIntensity = 30`
- `maxDurationMs = 1000`
- 不自动触发设备。

## 7. 测试点

- 配置不存在时生成默认配置。
- 配置损坏时进入安全模式。
- 缺失字段可自动补全。
- 非法强度和时间会被拒绝或修正。
