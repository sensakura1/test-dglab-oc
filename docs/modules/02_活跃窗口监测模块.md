# 活跃窗口监测模块开发文档

## 1. 模块职责

活跃窗口监测模块负责周期性读取当前前台窗口信息，用于判断用户是否处于写作范围、分心范围、忽略范围或暂停范围。

## 2. 采集内容

- 前台窗口进程名。
- 前台窗口标题。
- 可选浏览器 URL。
- 采样时间。

默认不持久化完整窗口标题和 URL。

## 3. 关键接口

```ts
interface WindowMonitor {
  start(): void;
  stop(): void;
  getCurrentWindow(): Promise<ActiveWindowInfo>;
  onChange(handler: (info: ActiveWindowInfo) => void): void;
}

interface ActiveWindowInfo {
  processName: string;
  title?: string;
  url?: string;
  capturedAt: string;
}
```

## 4. 采样策略

- 默认采样间隔为 `1000ms`。
- 用户暂停专注时停止采样。
- 锁屏、权限不足、窗口读取失败时返回 `UNKNOWN` 状态。
- URL 读取为可选能力，关闭后不影响进程名和标题匹配。

## 5. 隐私处理

- 日志中只记录命中的规则名称。
- 调试模式可临时显示窗口标题，但默认不保存。
- URL 读取需要用户显式开启。

## 6. 异常处理

| 异常 | 处理 |
| --- | --- |
| 无法读取窗口 | 返回未知窗口，不触发设备 |
| 无法读取 URL | 降级为标题和进程匹配 |
| 采样超时 | 跳过本轮采样 |

## 7. 测试点

- 能识别当前前台进程。
- 窗口切换后能更新状态。
- URL 读取关闭时程序仍正常。
- 读取失败不会导致触发。
