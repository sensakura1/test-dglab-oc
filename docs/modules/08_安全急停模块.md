# 安全急停模块开发文档

## 1. 模块职责

安全急停模块负责全局安全控制，包括急停、锁定、强度上限、持续时间上限、设备异常保护和真实设备确认。

## 2. 关键接口

```ts
interface SafetyController {
  emergencyStop(): Promise<void>;
  lock(reason: string): void;
  unlock(): void;
  isLocked(): boolean;
  clampActivation(input: CoyoteActivation): CoyoteActivation;
}
```

## 3. 急停流程

```text
用户点击急停或按快捷键
  -> 立即调用 CoyoteAdapter.stop()
  -> 设置 LOCKED 状态
  -> 通知 UI
  -> 记录急停日志
  -> 用户手动解锁前拒绝所有触发
```

## 4. 限幅规则

- `intensity <= maxIntensity`
- `durationMs <= maxDurationMs`
- 非法负数值按 `0` 或最小安全值修正。
- 配置异常时进入安全模式。

## 5. 测试点

- 急停能打断触发。
- 锁定状态拒绝新触发。
- 手动解锁后可恢复。
- 限幅对所有事件生效。
