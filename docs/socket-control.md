# Socket 控制协议连接

桌面端的 Socket 模式使用 DG-Lab Socket V2 WebSocket 协议。

## 连接流程

1. 在“连接模式”中选择“Socket 控制协议”。
2. 选择服务器方式：
   - “在本机建立 Socket 服务器”：填写手机可访问的本机 IP/域名和监听端口，然后启动服务。
   - “连接外部 Socket 服务器”：填写电脑和手机都能访问的 `ws://` 或 `wss://` 地址。
3. 页面会显示二维码和 App 手动连接地址。本地服务器会直接创建 `clientId`；外部服务器模式会等待服务器分配 `clientId`。
4. 在 DG-Lab App 的 Socket 控制页面扫描二维码，或手动填写页面显示的连接地址。
5. 页面显示“App 已绑定”后，桌面端才允许发送强度、波形清空和急停指令。

二维码在本机离线生成，服务器地址和绑定 ID 不会发送给第三方二维码服务。

本地服务器监听所有网卡。局域网使用时应填写电脑的局域网 IP，不能填写手机无法访问的 `127.0.0.1`；如果手机无法连接，还需要在 Windows 防火墙中允许所选 TCP 端口。

## 协议消息

控制指令通过标准 JSON 信封发送：

```json
{
  "type": "msg",
  "clientId": "桌面端 ID",
  "targetId": "App ID",
  "message": "strength-1+2+20"
}
```

停止输出时会清空 A/B 波形队列，并将两个通道强度设为 0。
