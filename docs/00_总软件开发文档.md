# 《OC 设定写作督促工具》总软件开发文档

## 1. 文档目的

本文档根据 [OC_Writing_Focus_Coyote_Development_Requirements.md](../OC_Writing_Focus_Coyote_Development_Requirements.md) 编写，用于指导软件架构设计、模块拆分、接口约定、开发顺序、测试策略和交付标准。

本工具是一个本地运行的写作专注督促程序。它监测用户是否处于 OC 设定写作范围内，当用户长时间离开写作页面、停留在分心页面或长时间无输入时，经过规则引擎校验后调用郊狼设备适配器进行督促触发。

当前实现阶段为模拟平台版本，只展示和记录模拟触发结果，不连接真实设备。

---

## 2. 总体原则

- 本地优先：所有监测、判断、日志和配置默认保存在本地。
- 隐私优先：默认不保存写作内容、完整窗口标题、完整 URL 和具体键入内容。
- 安全优先：真实设备默认关闭，所有触发必须经过强度、时长、冷却、次数和急停校验。
- 模块隔离：监测模块只产生事件，不能直接调用设备。
- 可测试优先：所有设备调用必须支持模拟适配器。
- 低性能开销：不做高频图像识别，不做高频全局扫描，默认使用活跃窗口和输入活跃度检测。

---

## 3. 推荐技术方案

### 3.1 运行平台

目标平台为 Windows 10 及以上。

### 3.2 推荐架构

推荐桌面端本地应用架构：

- 前端 UI：桌面界面，用于配置、状态展示、日志和急停。
- 主进程/后端服务：负责窗口监测、输入监测、规则引擎、设备调用和配置读写。
- 本地配置文件：保存用户配置。
- 本地日志文件：保存脱敏后的运行日志。

### 3.3 可选技术栈

| 层级 | 推荐 | 说明 |
| --- | --- | --- |
| UI | Tauri / Electron / Python Qt | 均可实现桌面应用 |
| 核心逻辑 | TypeScript / Python / Rust | 需便于调用 Windows API |
| 配置 | JSON | 简单可读，易迁移 |
| 日志 | JSON Lines | 便于筛选和脱敏 |
| 设备通信 | WebSocket / HTTP | 按郊狼接口实际协议适配 |

首版建议优先保证模块边界，而不是绑定具体框架。

## 4. 系统架构

```text
UI Layer
  -> AppController
  -> ConfigService
  -> SessionManager
  -> WindowMonitor
  -> InputActivityMonitor
  -> ScopeMatcher
  -> EventBus
  -> TriggerEngine
  -> SafetyController
  -> CoyoteAdapter
  -> LogService
```

### 4.1 数据流

```text
活跃窗口变化 / 输入活跃度变化
  -> 监测模块采样
  -> ScopeMatcher 判断状态
  -> SessionManager 统计离开、分心、空闲时间
  -> 生成 FocusEvent
  -> TriggerEngine 校验规则
  -> SafetyController 校验急停和安全上限
  -> CoyoteAdapter 执行模拟或真实触发
  -> LogService 记录脱敏日志
  -> UI 更新状态
```

### 4.2 关键状态

| 状态 | 说明 |
| --- | --- |
| `STOPPED` | 未开始专注 |
| `WRITING` | 当前处于写作范围 |
| `LEFT` | 已离开写作范围 |
| `DISTRACTED` | 当前命中分心范围 |
| `IDLE` | 长时间无输入 |
| `COOLDOWN` | 触发后冷却中 |
| `LOCKED` | 急停后锁定 |
| `PAUSED` | 用户手动暂停或命中暂停范围 |

## 7. 核心数据结构

### 6.1 AppConfig

```ts
interface AppConfig {
  enabled: boolean;
  deviceMode: "mock" | "real";
  sessionMinutes: number;
  leaveGraceSeconds: number;
  distractionGraceSeconds: number;
  idleGraceSeconds: number;
  cooldownSeconds: number;
  maxTriggersPerSession: number;
  maxIntensity: number;
  maxDurationMs: number;
  emergencyStopKey: string;
  privacy: PrivacyConfig;
  writingScope: ScopeRule[];
  distractionScope: ScopeRule[];
  ignoreScope: ScopeRule[];
  pauseScope: ScopeRule[];
  triggers: Record<FocusEventType, TriggerProfile>;
  coyote: CoyoteConfig;
}
```

### 6.2 FocusEvent

```ts
type FocusEventType =
  | "FOCUS_LEFT"
  | "DISTRACTION_DETECTED"
  | "IDLE_TOO_LONG"
  | "SESSION_TIMEOUT"
  | "MANUAL_TEST";

interface FocusEvent {
  type: FocusEventType;
  occurredAt: string;
  source: "window" | "input" | "session" | "manual";
  ruleName?: string;
  elapsedSeconds?: number;
}
```

### 6.3 CoyoteActivation

```ts
interface CoyoteActivation {
  intensity: number;
  durationMs: number;
  channel: "A" | "B" | "both";
  pattern: "constant" | "pulse";
}
```

## 9. 测试策略

| 测试类型 | 范围 |
| --- | --- |
| 单元测试 | 配置校验、范围匹配、冷却、强度限幅 |

| 隐私测试 | 不记录输入内容、不记录完整 URL |
| UI 测试 | 配置保存、状态切换、测试触发 |
